# Sakura Calc 🌸

Розовый аниме-калькулятор на HTML, CSS и JavaScript без зависимостей.

Запуск: `npm run dev`, затем открыть http://127.0.0.1:4173.
Проверка вычислений: `npm test`.

Обычные операции выполняются с математическим приоритетом. Процент означает деление числа на 100: `200 × 15 % = 30`. Расширенный режим добавляет скобки, π, квадрат, корень и обратное число. История (до 30 записей) и настройки сохраняются в localStorage этого браузера. Enter вычисляет, Escape очищает, Backspace удаляет символ.

Оригинальная иллюстрация создана встроенным ImageGen. Шрифты Comfortaa и Nunito загружаются из Google Fonts; при отсутствии сети используются системные шрифты.
